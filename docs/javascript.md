# JavaScript

Welcome! This note is your guide to learning programming with [JavaScript](https://en.wikipedia.org/wiki/JavaScript). JavaScript is one of the most popular languages for building web applications, and learning it will open doors to many exciting projects. We'll start with the basics and gradually move to more advanced topics, including building your own web apps.

## Why JavaScript?
- Runs in every modern browser
- Powers interactive websites and web apps
- Easy to start, but deep enough for advanced development

## Tools

To get started, install these essential tools:

1. **Node.js** ([nodejs.org](https://nodejs.org/)) — Lets you run JavaScript outside the browser to focus on programming fundamentals.
2. **Visual Studio Code** ([code.visualstudio.com](https://code.visualstudio.com/)) — A powerful code editor with great support for JavaScript.
3. **Git** ([git-scm.com](https://git-scm.com/)) — Version control to track your code changes and collaborate.

## How to run a JavaScript program

1. Create a new JavaScript file (e.g., `app.js`).
2. Write your JavaScript code in the file.
3. Open your terminal and run: `node app.js`
